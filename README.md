# 2D Soccer Game (Pygame)

A two-player 2D soccer game built using **Python and Pygame**. 

##  Gameplay Overview
- Local two-player soccer match
- Real time player movement and ball physics
- Goal detection with live score tracking
- Interactive menu and instructions screen

## Controls
**Player 1**
- Move: 'W A S D'

**Player 2**
- Move: 'Arrow Keys'

## 🛠️ Built With
- Python
- Pygame
